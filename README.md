# Student Assignment Tracker

A Java Swing desktop application to manage student assignments efficiently.

## Features
- Add new assignments
- Update assignment status
- Delete assignments
- Search assignments
- View all assignments
- Dashboard with assignment statistics
- Due date tracking
- Overdue assignment alerts
- Save assignment data locally

## Technologies Used
- Java
- Java Swing
- File Handling

## How to Run
1. Install the Java JDK.
2. Open the project in VS Code.
3. Compile and run AssignmentTrackerGUI.java.
